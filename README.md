# MSc.-Research
An AI-based model for providing guidance and privacy preservation for cyberbullying victims by predicting cyberbullying.

This research introduces an AI-powered application for real-time cyberbullying detection and victim support across social media. 1  Addressing escalating online harassment, the study leverages advanced machine learning, specifically a Support Vector Machine with a linear kernel, for accurate classification. Employing a mixed-methods design, it combines quantitative model evaluation (trained on a Kaggle dataset preprocessed with NLP and TF-IDF for feature extraction) with qualitative insights into user experiences. The application integrates with social media APIs for live analysis, generates personalized guidance and coping strategies based on classifications and user demographics, and offers access to support resources via a user-friendly interface with reporting features. Prioritizing user privacy through robust data protection, this project aims to significantly mitigate the impact of cyberbullying and foster a safer online environment
